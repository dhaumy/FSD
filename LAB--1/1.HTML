Bash Command I Have Learnt

1.touch

File creation

The touch command creates a new,empty file. If the file already exists, it simply updates the file's last modified timestamp intead of changing its content.
Its one of the simplest way to creat a file directly from the terminal.

Syntax : touch filename

Example : touch note.txt

Output :(no output - the file note.txt is created silently in the current folder)

2.mkdir

Folder creation

The mkdir command a new, empty folder(directory) at location you specify

Syntax : mkdir foldername

Example : mkdir project

Output : (no output - the folder project is created in the current directory)

3.cd

Changing directory

The cd command changes the current working directory, moving you into different folder in the terminal

Syntax : cd foldername

Exampte : cd project

Output :(prompt changes to show you are now inside ~/project)

My understanding : grep searches through the contents of a file (or files) for lines that match a given word or pattern, and it prints out only the matching lines rather than the whole file. This makes it usefull for quickly finding where a particular word or piece of text appears inside a large file without having to open and read it manually.
