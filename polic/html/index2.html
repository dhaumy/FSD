Bash Command I Have Learnt

1.touch

File creation

The touch command creates a new,empty file. If the file already exists, it simply updates the file's last modified timestamp intead of changing its content. Its one of the simplest way to creat a file directly from the terminal.

Syntax:touch filename
Example: touch notes.txt

Output: (no output - the file note.txt is created silently in the current folder)

2.mkdir

Folder creation

The mkdir command creates a new, empty folder(directory) at the location you specify

Syntax : mkdir foldername
Example : mkdir project

Output : (no output - the folder project is created in the current directory)

3.cd

Changing directory

The cd command changes the current working directory, moving you into different folder in the terminal

Syntax : cd foldername

Exampte : cd project

Output :(prompt changes to show you are now inside ~/project)
